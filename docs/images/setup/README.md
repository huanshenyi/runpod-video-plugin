# 初回認証スクリーンショットの差し替え

ルートREADMEの4つの「画像差し込み枠」に対応します。利用者が用意した画像だけをここへ置いてください。

| ファイル名 | 撮影する内容 |
|---|---|
| 01-api-keys.png | CredentialsのAPI Keysタブと作成ボタン |
| 02-create-api-key.png | APIキーの名前・権限を選ぶ作成前画面 |
| 03-doctor.png | ローカル端末でrunpodctl doctorを実行した画面 |
| 04-healthy.png | healthy: trueと各チェックのpass |

APIキー全文・一部、秘密鍵、メールアドレス、個人名を含むパスなどは画像へ含めないでください。切り抜きや塗りつぶし後の画像を保存し、公開前に見直します。

画像追加後はルートREADMEの対応する引用枠をMarkdownの画像表示へ置き換えます。例：感嘆符＋角括弧で説明＋丸括弧内に `docs/images/setup/01-api-keys.png` を指定します。画像がない段階では壊れた画像リンクを作りません。
