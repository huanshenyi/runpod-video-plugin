# 切り出しとローカル確認

公開候補: `0.1.0-alpha.3`。既存の個人制作環境からコードのみを独立させました。

- 元のプラグイン・制作素材・個人設定は変更していません。
- 特定作品の固定パスを取り除き、2カードの初期化と任意README設定に対応。
- CLIを同梱バイナリからPATHまたはRUNPODCTL_BINへ変更。
- 任意MCP接続のTOML出力、公開用スキル、参考APIグラフを同梱。
- README・導入・検証結果・残作業・公開手順を整理。
- APIキー、SSH鍵、Pod/IP情報、個人ホームパス、作品素材、モデル重み、元の実行ログは含めていません。

確認結果: macOS / Node23.4.0で `npm ci`、**24テスト**、TypeScriptチェック、Viteビルド成功。互換プラグインmanifest検査、2スキル検査、文書リンクと配布物の簡易検査成功。GitHub ActionsのNode22/24ジョブは設定のみで、まだGitHub上では実行していません。公式ディレクトリへの登録・審査や他OSの実機動作を保証する確認ではありません。

配布フォルダとZIPはソースのみです。起動前に `node scripts/board.mjs prepare` を実行してください。ライセンスの選択と公開名義・URLの設定、Git初期化・pushは公開者が行います。

Alpha2ではmarketplace登録と初回利用時の自動セットアップ入口を追加しました。Alpha1の24テストという数字はその時点の記録です。最新版の確認結果はリポジトリルートのVERIFICATION.mdを参照してください。
